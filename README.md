## 关于我

我是 hpoenixf。2016 年起从事软件研发，具有前端工程背景，曾就职于阿里、腾讯及外企，目前专注金融科技与 AI Agent 应用研发。

- **从界面到交付：** 关注设计系统、复杂交互、状态管理与端到端质量。
- **从模型到系统：** 关注工具、上下文、记忆、恢复及交付怎样协同工作。
- **从数据到结论：** 关注金融数据口径、计算可复现和结果可追溯。

## 正在构建

### [Open ETF Agent](https://github.com/hpoenixf/open-etf-agent)

从一份能打开、能核对来源的报告开始，逐版构建研究 Agent。保留可运行代码、Spec、失败与修复记录，让文章中的机制有可以动手验证的入口。

**[运行 v0.5](https://github.com/hpoenixf/open-etf-agent/tree/phase/v0.5)** · [查看各阶段](https://github.com/hpoenixf/open-etf-agent/branches) · [演进证据](https://github.com/hpoenixf/open-etf-agent/blob/05c0dd2dc550f4f7e5da034340ff5c3159768fcf/docs/evolution/evidence-index.md)

v0.1–v0.5 已公开，覆盖工具循环、Skills / MCP、Hooks、受限分工、结果外置、压缩与显式 Memory。当前入门示例使用合成文档；程序验证与真实模型验收分别记录。它仍在逐版开发中，不是生产金融服务或投资建议。
